# 成都工贸职业技术学院「未来学习中心」设计规范

> 版本：1.0 · 提取日期：2026-07-23  
> 范围：当前首页（`index.html`）桌面与移动端。本文是**对现有页面的设计 DNA 提取与规范化**，不是重新设计提案。

## 1. 设计 DNA

**一句话定义：** 以「学院真实场景」建立信任，以「亮蓝科技光感」表达数字化学习能力，用大留白、轻玻璃与卡片化信息降低教育平台的信息负担。

| DNA 维度 | 明确规则 | 页面中的落点 |
|---|---|---|
| 品牌气质 | 专业、可信、清朗、面向未来；避免赛博黑、过度炫光或商业化促销感。 | 校园实景英雄图、克制的浅蓝背景、规范的网格。 |
| 色彩逻辑 | 蓝色为唯一主导色；青色用于科技活力；暖黄只作少量提示与成就点缀。 | 主按钮/图标/标题标记使用蓝；标签和光晕使用青、黄。 |
| 空间感 | 宽容器、大段留白、整齐网格；关键模块用「悬浮跨界」产生层次。 | 800px Hero、负边距快捷入口、78px 区块间距。 |
| 表面语言 | 纯白或极浅蓝面，配半透明玻璃、细边框和柔软阴影；不使用厚重描边。 | 导航、快捷面板、「查看更多」按钮、各类卡片。 |
| 信息层级 | 中文标题承担识别，英文大写副标题承担科技感；数据和标签为第三层。 | 章节标题、`Virtual Exhibition`、资源库数据格。 |
| 动效性格 | 短、轻、上浮，不做大幅位移；所有动效都必须尊重减少动态效果设置。 | 卡片 hover 上移 5px、按钮上移 1px、齿轮图标微动。 |

## 2. 布局与响应式

### 2.1 画布与栅格

| 项目 | 规范 |
|---|---|
| 最大内容宽度 | `1440px` |
| 桌面左右安全边距 | `24px`；内容宽度：`min(1440px, 100% - 48px)` |
| 实测 1280px 视口内容宽度 | `1217px` |
| 移动端左右安全边距 | `16px`；内容宽度：`100% - 32px` |
| 主区块下间距 | 桌面 `78px`；移动 `58px` |
| 浅色分区上下内边距 | 桌面 `76px`；移动 `56px` |
| 卡片间距 | 常规大网格 `22px`；资源网格 `18px`；快捷入口 `12px` |
| 首屏 | 桌面固定/最小高度 `800px`；移动最小高度 `560px` |

### 2.2 断点与列数

| 宽度 | 导航 | 快捷入口 | 主内容卡片 | 资源区 | 页脚 |
|---|---|---:|---:|---:|---:|
| `> 1260px` | 单行胶囊导航 | 8 列 | 4 列 | 侧栏 260px + 3 列 | 4 列 |
| `1121–1260px` | 收紧横向间距 | 8 列 | 4 列 | 不变 | 4 列 |
| `761–1120px` | 菜单改为深蓝浮层、2 列 | 4 列 | 2 列 | Tab 2 列、内容 2 列 | 2 列 |
| `≤ 760px` | 单列展开菜单 | 2 列 | 1 列 | Tab / 内容均 1 列 | 1 列 |

**栅格原则：** 每个内容卡片的宽度随列数伸缩；图片卡默认用 `16:9` 封面，原型或已确认需求指定竖版比例时按其执行。不要在同一视觉层级里混用 3、4、5 列，避免打破整齐的教学资源陈列感。

## 4. 色彩使用规范

| 角色 | 值 | 用途 | 不应使用的场景 |
|---|---|---|---|
| 主品牌蓝 | `#176BDB` | 主要交互、数据高亮、图标、标题装饰 | 大面积正文、长文本 |
| 深蓝 | `#0C4CA3` | 次级按钮文字、深层品牌区、页脚过渡 | 普通卡片背景 |
| 科技青蓝 | `#19A7E8` | 与主蓝组成渐变、强调边缘光感 | 独立承担大量文字 |
| 青绿 | `#44D7C4` | 背景光晕、状态标签、辅助点缀 | 主操作按钮 |
| 暖黄 | `#FFD766` | Hero 眉标光点、金色标签、焦点环 | 大面积底色或正文文字 |
| 主文字 | `#172033` | 标题、正文主体 | 英文副标题/弱说明 |
| 次要文字 | `#65738A` | 摘要、元数据、地点说明 | 关键操作或高密度正文 |
| 页面底 | `#F3F8FF → #FFF` | 整体氛围、分区过渡 | 卡片内主要阅读区 |

**渐变规则：** 只使用 `135deg` 的主蓝→青蓝渐变于图标、选中 Tab、品牌型动作；背景光晕透明度保持在 `4%–18%`，保证教育信息的清晰度优先于装饰。

## 5. 字体与文字层级

```css
--font-body: "SF Pro Display", "Helvetica Neue", Helvetica, Tahoma, Arial,
             "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
--font-display: "Alibaba PuHuiTi 3.0", "PingFang SC", "Microsoft YaHei", sans-serif;
```

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---:|---|
| Hero 标题 | `clamp(48px, 5.4vw, 78px) / 1.08`；移动 `38–50px` | 900 | 仅首页/大型专题首屏 |
| Hero 副标题 | `22–32px / 1.3` | 800 | 学校或栏目归属 |
| 区块标题 | `clamp(28px, 3vw, 42px) / 1.2` | 900 | 一级栏目 |
| 卡片标题 | `20–21px / 1.28` | 900 | 专业、课程、仿真、资源名称 |
| 新闻标题 | `18px / 1.45` | 900 | 信息列表主标题 |
| 正文/摘要 | `14–16px / 1.62–1.80` | 400 | 概述、摘要、介绍 |
| 元数据 | `12–13px / 1.4` | 700–800 | 教师、课时、地点、标签 |
| 英文副标题 | `15px / 1.2`，字距 `0.08em`，全大写 | 800 | 章节功能性英文名 |

**排版规则：** 中文主标题不强行增加字距；英文只作为辅助，不与中文争夺首要视觉权。正文最大宽度为 Hero `710px`、标题 `740px`，保持可读行长。

### 5.3 二级页桌面 Hero 基线

| 属性 | 规范 |
|---|---|
| Hero 高度 | 桌面固定 `500px`；移动端固定 `340px` |
| 中文主标题 | `64px / 1.06`，900 字重 |
| 简介字段 | 所有二级页不展示简介字段；Hero 仅保留栏目识别信息与标题，不增加介绍性段落。 |
| 背景 | 左侧保留文字安全区，并在背景资源内以低透明度科技流光或几何立方体提供细微层次；科技立方体、流光等细节必须内嵌于背景图素材，不以页面 CSS 装饰层叠加；禁止网格、横竖线条纹理干扰主视觉。 |
| 可读性蒙层 | 左侧标题安全区允许叠加低透明度品牌蓝渐隐蒙层，处理方式参照“教学成果库”Hero：从左侧较高透明度蓝色过渡至中部透明，不遮挡右侧视觉焦点。 |
| 主内容区 | 有横向 Tab 或模块标题：上 `50px`、下 `60px`；无 Tab / 标题：上 `64px`、下 `60px`。 |
| 二级页检索 | 所有二级页 Hero 默认保留关键词检索框，沿用课程中心与教材成果库的胶囊输入框和品牌渐变搜索按钮；仅在页面需求明确排除检索时才可省略。 |
| 移动端页脚 | 品牌介绍和服务支持各占全宽；“平台应用”与“建设中心”在同一行左右排列。二级页须接入 `assets/css/site-mobile-shell.css`，以同步该规则及移动端 Hero 基线。 |

## 6. 组件规范

### 6.1 悬浮导航

| 属性 | 规范 |
|---|---|
| 位置 | 距顶部 `24px` 固定；移动端 `12px` |
| 尺寸 | 最小高度 `84px`；移动端 `66px` |

| 离开 Hero 后 | 蓝色半透明渐变底、白色文字；Logo 换为反白版本 |
| 窄屏 | 1120px 以下改深蓝浮层菜单，菜单项最小点击高度 `44px` |

### 6.2 快捷入口

| 属性 | 规范 |
|---|---|
| 容器 | 位于 Hero 下方，向上覆盖 `76px`；白色 `94%` 玻璃面，圆角 `28px` |
| 单元 | 最小高 `112px`，圆角 `18px`，内边距 `16px 10px` |
| 图标 | `50 × 50px`，圆角 `16px`，主蓝→青蓝渐变、白色单色图标 |
| 文字 | 15px / 800，居中 |
| Hover | 上移 `5px`，边框增强至蓝色 `28%`，提升为卡片阴影 |

### 6.3 内容卡片

| 变体 | 尺寸与结构 | 关键细节 |
|---|---|---|
| 专业卡 | 最小高 `260px`，内边距 `24px` | `58px` 图标徽章、21px 标题、双标签 |
| 二级列表课程卡 | 最小高 `288px`，横版 `16:9` 封面 | 标题默认 `18px`；教师与学校等元信息为 `16px`，可同行展示 |
| 仿真卡 | 最小高 `258px`，`16:9` 封面 | 20px 标题、地点图标及位置文字固定在底部 |
| 资源卡 | 最小高 `210px`，内边距 `22px` | 三个浅蓝数据格；数值 20px 品牌蓝 |
| 所有卡片 | `18px` 圆角、浅蓝细边、柔阴影、极浅蓝到白渐变 | Hover 统一上移 `5px`，标题变品牌蓝 |

### 6.4 标签、图标、按钮

| 组件 | 规范 |
|---|---|
| 普通标签 | 高 `28px`，水平内边距 `10px`，全圆角，蓝色 `8%` 底、深蓝字，12px/800。 |
| 金色标签 | 黄 `22%` 底，文字 `#8A5C00`；仅表示荣誉、培养重点或高价值特征。 |
| 状态标签 | 高 `30px`，青绿 `12%` 底、深青字；用于课程等级或积极状态。 |
| 图标徽章 | `58 × 58px`，圆角 `18px`；图标为白色、单色线性或实心风格，不混用多风格图标。 |
| 次级动作（查看更多） | 高 `48px`，白玻璃底、全圆角、14–16px/800 深蓝字；右侧使用 22px 小齿轮/箭头。Hover 上移 `1px`，Active 缩放至 `0.98`。 |
| Tab | 高 `68px`，圆角 `18px`；选中态为主蓝→青蓝渐变 + 白字，未选中为白色半透明底。 |

### 6.5 标题区与分区

章节标题左侧使用 `18 × 18px` 的渐变方块，圆角 `4px`，并向右下投射 `8px 8px` 的浅蓝方形阴影。标题下方放置英文全大写副标题；标题组与内容之间间距 `28px`（移动 `22px`）。浅色分区采用白→浅蓝的纵向或斜向渐变，允许少量青色/黄色径向光晕。

### 6.6 二级页数据列表与分页

- 二级页中出现的分页必须使用全站统一分页组件：上一页、当前页、连续页码、省略号、末页与下一页保持同一顺序和视觉状态；首页状态中的上一页为禁用态、当前页使用品牌蓝实底白字，其余页码为白色圆角按钮。
- 分页仅表达已确认的静态数据状态，除非需求明确，否则不接入数据加载、路由或详情页。
- 模块字段、字段标签、内容文案与数据数量优先直接沿用原型；只有原型明确缺失时，才按页面语义补充示例内容。用户后续确认的页面专属要求可覆盖原型。
- 二级页不展示简介字段，包括 Hero 中的介绍性段落和列表卡片的简介字段；除栏目识别信息与标题外，不额外补充简介文案。
- 原型未提供的数据，按页面或所在模块主题补充简洁、可信的示例文案；不得以无关占位符替代。
- 当模块需要封面图时，必须按模块语义独立检索并下载已核验可免费商用的素材，记录必要署名；不得照搬原型封面，也不得仅因方便复用无关的项目既有图片。普通封面宽度不得超过 `1000px`，比例以原型或已确认页面要求为准。

## 7. 图像与背景规范

| 场景 | 处理规则 |
|---|---|
| Hero | 使用真实校园/学习场景作满幅背景；左侧预留文字安全区，右侧可放数字化教育意象。叠加深蓝至透明遮罩，确保白字可读。 |
| 内容封面 | 默认 `16:9`、`object-fit: cover`；原型或已确认需求指定其他比例时遵从其比例。优先使用与模块语义对应的设备、课堂、实训、场景仿真等画面。 |
| 展厅/数据大屏 | 放在白色大圆角容器中，容器圆角 `30px`，以柔和阴影制造「设备展示窗」质感。 |
| 页脚 | 深蓝渐变承载学院归属；背景图仅作为约 `12%` 不透明度的纹理，不能影响链接阅读。 |
| 禁忌 | 不使用无关的国际校园图库、强饱和霓虹背景、人物占满文本安全区的图片。 |

## 8. 交互、动效与无障碍

## 附：Figma 网页捕获固定规则

适用于后续所有网页捕获为 Figma 可编辑画板（桌面端）：

- 顶层画板固定为 **1920px 宽**，不得以内容区宽度代替画板宽度。
- 每个桌面模块的主内容区固定为 **1440px 宽并水平居中**；全宽背景、Hero 与页脚可延展至 1920px。
- 捕获后先读取目标文档已有的颜色、圆角、间距变量，以及效果、文本样式；仅当画板原始参数与已有规则一致或近似无可见差异时才绑定。
- 若字号、色值、间距、圆角或效果与已有规则存在明显差异，保留网页源格式，不强行统一。
- 每次实际绑定前先输出「计划绑定 / 保留源格式」差异清单，取得确认后再写入 Figma。

---

### 8.1 动效

| 触发 | 动作 | 时长 / 缓动 |
|---|---|---|
| 卡片 hover | `translateY(-5px)` + 阴影升级 + 标题变蓝 | `220ms ease` |
| 常规链接 hover | 背景/文字切换，上移 `1px` | `200ms ease` |
| 次级按钮 hover | 上移 `1px` | `180ms cubic-bezier(.25, 1, .5, 1)` |
| 次级按钮 active | 回位并 `scale(.98)` | 即时 |
| 菜单按钮 | 三线变叉 | `220ms ease` |

当系统开启 `prefers-reduced-motion: reduce` 时，所有动画和过渡应降到 `0.01ms`，平滑滚动关闭，动态齿轮改为静态图标。

### 8.2 无障碍底线

- 所有键盘焦点使用 `3px` 暖黄描边，外扩 `3px`；焦点不得只依赖颜色变化。
- 首个可聚焦元素是「跳至主要内容」链接；聚焦时固定显示在左上角。
- 图像提供准确 `alt`；纯装饰图标使用 `aria-hidden="true"`。
- Tab 使用 `role="tablist"`、`role="tab"`、`aria-selected` 与对应 `tabpanel`；切换时同步状态。
- 所有可点击目标最小高度为 `44px`；主要按钮与导航在移动端不小于此值。
- 正文与背景需优先保证可读性；图片上的白色正文必须配深色遮罩，浅灰文案不承担关键操作信息。

## 9. 前端落地规则

1. 新组件不得直接写新的色值、圆角和阴影；优先引用第 3 节语义/组件令牌。
2. 保持「图标渐变 + 白卡 + 浅蓝边 + 柔阴影」这一组合，不新增玻璃拟态以外的材质语言。
3. 一组同级卡片必须高度对齐；使用 `flex` 将底部元信息或操作固定到卡片底部。
4. Hero、展厅、数据大屏使用 `overflow: hidden` 与大圆角，避免媒体溢出破坏干净边界。
5. 页面滚动后导航使用反白 Logo 与深蓝半透明背景；这是维持导航在浅底内容区可读性的必要状态。
6. 新增栏目沿用「中文标题 + 英文大写副标题 + 渐变方块标题标记」；若无英文命名，宁可省略也不要使用生硬翻译。

## 10. 验收清单

- [ ] 1440px 宽以内内容最大宽度不超过 `1440px`，桌面左右至少 `24px`。
- [ ] 1280px 桌面预览中，Hero 为 `800px` 高，快捷入口覆盖 Hero 底部约 `76px`。
- [ ] 所有同级卡片使用 `18px` 圆角、蓝色低对比边框和统一 Hover 行为。

- [ ] `1120px` 以下菜单、网格、资源区正确切换为中间断点布局；`760px` 以下内容为单列或两列快捷入口。
- [ ] 键盘 Tab 可见焦点，跳转链接、菜单、资源 Tab 均可操作。
