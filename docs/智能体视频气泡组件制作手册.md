# 智能体视频气泡组件制作手册

本手册用于在任意静态网页中复用“智能体视频 + 左上角气泡提示”组件。复用时通常只需替换视频文件和两行文案；位置、尺寸和视觉样式可按下表微调。

## 成品规格

| 项目 | 当前规格 |
| --- | --- |
| 载体 | 透明背景 `.webm` 视频或动画 `.gif` |
| 视频展示 | 高 `180px`，宽度自动，保持原始长宽比 |
| 播放方式 | WebM 使用自动播放、静音、循环、内联播放；GIF 由浏览器自动循环 |
| 组件位置 | Hero 内右侧 `80px`、底部 `108px` |
| 气泡位置 | 视频左上方；相对视频左移 `40px`、下移 `30px` 后的现有位置 |
| 气泡尺寸 | 宽 `258px`；内边距 `12px 18px`；字体 `15px` |
| 气泡形状 | 左上、右上、左下为 `18px` 圆角；右下直角 |
| 气泡底色 | `145deg` 白色渐变，左侧 `18%`、右侧 `3%` 透明度 |
| 描边 | 独立的 `1px` 白色透明渐变描边，不与底色叠加 |

## 1. 准备并替换视频

1. 可使用带透明通道的 `.webm` 文件，或带透明背景的动画 `.gif`；建议内容主体已留出少量透明边缘，避免角色贴边。
2. 将文件放进项目的 `assets/video/` 目录。
3. 最省事的替换方式是保留文件名：用新文件覆盖当前使用的资源。页面代码无需改动。
4. 若使用新文件名，只改组件资源路径即可，例如 `./assets/video/assistant-robot.gif` 或 `./assets/video/assistant-robot.webm`。

不要重新编码当前文件来“压缩”。浏览器展示时会按 `height: 180px` 缩放，但源文件会原样加载；`object-fit: contain` 会保持长宽比，不会拉伸变形。GIF 请使用 `<img>` 直接引用；它本身会自动播放与循环。

## 2. 替换气泡文案

在页面 Hero 内找到以下结构，只替换 `<div class="agent-message">` 中的两行文字即可。`<br>` 用于强制换行。

```html
<aside class="agent-assistant" aria-label="智能体提示">
  <div class="agent-message">你好，我是智能体名称<br>有任何问题都可以点我提问哦</div>
  <img class="agent-video" src="./assets/video/assistant-robot.gif" alt="" aria-hidden="true">
</aside>
```

文案建议保持两行，每行不超过约 16 个中文字符。若文案更长，适当增大 `width`，不要删除 `white-space: nowrap`，否则可能出现意外断行。

## 3. 复制样式

将以下 CSS 放入页面样式中。父容器必须是 `position: relative`；本项目使用的 `.hero` 已满足此条件。

```css
.agent-assistant {
  position: absolute;
  right: 80px;
  bottom: 108px;
  z-index: 45;
  display: inline-block;
  pointer-events: none;
}

.agent-video {
  height: 180px;
  width: auto;
  display: block;
  object-fit: contain;
}

.agent-message {
  position: absolute;
  right: calc(100% - 6px);
  bottom: 104px;
  width: 258px;
  padding: 12px 18px;
  border: 1px solid transparent;
  border-radius: 18px 18px 0 18px;
  background: linear-gradient(145deg, rgb(255 255 255 / 18%) 0%, rgb(255 255 255 / 3%) 100%) padding-box;
  color: #fff;
  box-shadow: 0 6px 14px rgba(9, 27, 69, 0.22);
  font-size: 15px;
  font-weight: 700;
  line-height: 1.55;
  letter-spacing: 0.01em;
  white-space: nowrap;
  -webkit-backdrop-filter: blur(8px);
  backdrop-filter: blur(8px);
}

/* 仅绘制 1px 描边；不会叠加到气泡底色。 */
.agent-message::before {
  content: "";
  position: absolute;
  inset: -1px;
  padding: 1px;
  border-radius: inherit;
  background: linear-gradient(145deg, rgb(255 255 255 / 78%) 0%, rgb(255 255 255 / 22%) 100%);
  pointer-events: none;
  -webkit-mask:
    linear-gradient(#000 0 0) content-box,
    linear-gradient(#000 0 0);
  -webkit-mask-composite: xor;
  mask-composite: exclude;
}

@media (max-width: 760px) {
  .agent-assistant { display: none; }
}
```

## 4. 放置位置：Hero 内或浏览器窗口内

推荐放在 Hero 内：将上述 HTML 放进 `<header class="hero">`，并保留 `.agent-assistant { position: absolute; }`。组件会始终属于首屏 Hero，向下滚动时随 Hero 离开，不会覆盖后续内容。

如果项目确实需要它始终悬浮于浏览器右下角，将 `position: absolute` 改成 `position: fixed`，并把 HTML 放在 `</body>` 前。其余样式不变。

## 5. 常用调整项

| 需求 | 调整项 |
| --- | --- |
| 向左移动气泡 | 增大 `agent-message` 的 `right` 值；例如从 `calc(100% - 6px)` 改为 `calc(100% + 34px)` 会再左移 `40px` |
| 向下移动气泡 | 减小 `agent-message` 的 `bottom` 值；每减小 `10px` 即下移 `10px` |
| 移动整组 | 调整 `agent-assistant` 的 `right` 或 `bottom` |
| 改视频高度 | 修改 `agent-video` 的 `height`；`width: auto` 保持不变 |
| 改气泡宽度 | 修改 `agent-message` 的 `width` |
| 改底色透明度 | 修改第一条 `linear-gradient` 中的 `18%` 与 `3%`；二者等比调整可维持渐变层次 |
| 改描边亮度 | 修改 `::before` 渐变中的 `78%` 与 `22%`；不要把该渐变合并到 `agent-message` 的 `background` 中 |

## 6. 验收清单

- 桌面端加载页面后，视频自动开始、静音循环播放。
- 视频高度正确，角色没有被拉伸或裁切。
- 气泡显示在视频左上方，文字恰好分两行。
- 气泡右下角为直角，其余三个角为圆角。
- 描边仅出现在 1px 边缘；气泡中心没有因描边额外变白。
- 下滑离开 Hero 后，整个组件随 Hero 一起离开视口。
- 窄屏（≤ `760px`）页面不显示该组件。

## 常见问题

**WebM 不能自动播放**：确认视频元素同时包含 `autoplay muted loop playsinline`。大多数浏览器会阻止非静音自动播放。GIF 则使用 `<img>` 直接引用，不需要这些属性。

**气泡看起来过于不透明**：检查是否把“底色渐变”和“描边渐变”写在同一个 `background` 属性中。若第二层使用 `border-box`，它会覆盖整个气泡并与底色叠加。请保持本手册中的 `::before` 掩膜描边写法。

**文字不清晰**：浅色或透明背景上白色文字需要有足够深的 Hero 背景。如果目标背景较亮，优先降低气泡透明度或将文字改为深色，而不是加厚整块底色。
